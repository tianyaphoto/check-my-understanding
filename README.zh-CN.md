# check-my-understanding

[English](README.md)

一个 [Claude Code](https://claude.com/claude-code) 技能，用来测你对一个主题理解到什么程度。它出一套自适应的题，每答一题马上讲评，最后给出每个概念的 0–5 级、掌握度得分，以及错答背后的错误认识和该读哪里。学完之后可以复测，用同一把量尺看哪些变了。

它是测量工具，不是老师，不负责从零讲一个主题。

## 安装

把仓库克隆到技能目录：

```bash
git clone https://github.com/tianyaphoto/check-my-understanding ~/.claude/skills/check-my-understanding
```

只想在某个项目里用，就克隆到 `<项目>/.claude/skills/check-my-understanding`。更新时在该目录执行 `git pull`。

新开一个 Claude Code 会话即可使用，没有其他依赖。

## 使用

直接说要测什么：

- `测测我对 Raft 的理解`
- `用这份文档给我摸底：docs/design.md`
- `复测 Raft`（学完薄弱点之后）

第一次运行时技能会问记录放哪里，并把答案写进 `~/.config/check-my-understanding/config.json`：

```json
{ "records_dir": "~/notes/understanding-checks", "default_questions": 20, "default_target_level": 4 }
```

摸底默认 20 题，大约 30 分钟。可以答“不知道”，也可以随时说“暂停”，之后接着测。

## 工作方式

1. **资料**：你给的材料就是标准答案。只给主题名时，技能会先找 3–5 个权威来源读完。
2. **冻结的量尺**：建一棵 4–8 个概念的知识树，每个概念每一级对应一项可检验的能力。建好后不再改，所以每次测验用的是同一把尺。
3. **测验**：每个概念先问一道开放题（怎么运作、为什么这样设计），一题定出 0–3 级，题干不泄题。到 3 级的概念再考一道目标级别的场景题。剩下的题用来查知识树里记录的常见误解。
4. **报告**：每个概念的级别、掌握度得分、一到三个根本问题，每个都附证据、在实际工作中的后果和该读的章节。
5. **复测**：全部是换了情境的新题。上次的每个根本问题都会重新验证，标为已解决、部分解决或仍然存在。

| 级别 | 含义 |
|---|---|
| 0 | 不认识这个概念 |
| 1 | 听说过 |
| 2 | 知道是什么 |
| 3 | 知道为什么这样设计 |
| 4 | 会用，知道边界（默认目标） |
| 5 | 能和其他方案做取舍 |

## 评测

`evals/` 是开发这个技能时用的测试工具。一个模拟学习者按事先设定的水平（包括两个错误认识）做摸底和复测；一个独立会话从对话记录里提取事实；脚本对照设定的水平算分：测量准确 30、诊断 20、复测闭环 20、流程 15、量尺与记录 15。

同样条件下，当前版本得 100 分，上一版 92.8 分。这两个数字要保守看待：每个版本只跑了一次，100 分由相邻两个修订版各跑一条学习者链拼成，测试材料比真实文档规整。没有真人参与。

运行方法（需要 `claude` 命令行；一条学习者链大约消耗等价 20–55 美元的用量）：

```bash
cd evals
./run_chain.sh mytag /path/to/skill p1   # 有两个错误认识的学习者
./run_chain.sh mytag /path/to/skill p3   # 只背了定义的学习者
python3 score.py runs/mytag
```

不要中途杀掉一条链再用同一个标签重跑，残留的会话会把记录写进新的一轮。
